# MindBridge

AI와 고민을 이야기하면 CBT(인지행동치료) 방식으로 마음을 정리해 주고, 분석 리포트를 PDF로 남길 수 있는 마음 돌봄 웹앱입니다.

- 서비스 주소: https://mindbridge-mvp.vercel.app
- 저장소: https://github.com/gaeun73/mindbridge-mvp

> MindBridge는 AI가 생성한 **자기점검 도구**이며 의학적 진단이나 치료가 아닙니다.

## 해결하려는 문제

- 힘든 일이 있어도 "상담받을 정도인가" 싶어 망설이게 되고, 비용과 시간도 부담입니다.
- 혼자 생각하면 같은 부정적인 생각이 반복되기 쉽습니다.
- 내 감정과 생각을 정리해서 말하는 것부터 어렵습니다.

## 누가 쓰나요

- 일상의 스트레스·불안·자책으로 마음이 복잡한 사람
- 생각을 글로 정리하는 데 도움이 필요한 사람
- 상담 전에 내 상태를 미리 정리해 가고 싶은 사람

회원가입 없이 익명으로 바로 시작할 수 있습니다.

## 주요 기능

| 화면 | 설명 |
|---|---|
| 홈 | 인사 문구, 대화 시작 버튼, 지난 마음정리 목록(날짜·제목) |
| AI 마음 대화 | CBT 규칙 기반 채팅. [조금 더 대화하기]를 누르면 AI가 다음 질문을 먼저 던집니다. [대화 요약하기]는 메시지를 1개 이상 보내면 활성화됩니다. |
| 오늘의 마음정리 | 상황, 감정과 강도, 자동적 사고, 인지 왜곡(이름·설명·근거), 대안적 생각, 마음 챙김, 작은 행동. 탭으로 전체 / 논리적 분석 / 공감적 위로를 나눠 봅니다. |
| PDF 내보내기 | 인쇄용 레이아웃 + 브라우저 "PDF로 저장". 대화 원문은 기본 제외, 체크하면 포함합니다. |
| SOS | 109(자살예방상담전화), 1577-0199(정신건강위기상담), 119 전화 연결 |
| 상담사 보기 (`/counselor`) | 이 브라우저의 가장 최근 마음정리를 상담사 관점으로 보여주는 읽기 전용 데모 |

## 위기 대응

AI 응답의 `risk_level`로 세 단계로 나눕니다.

- `high`: 자해·자살 의도나 계획이 분명할 때만. 대화를 멈추고 SOS 화면으로 이동합니다.
- `low`: 애매한 표현. 대화는 계속하되 상단에 안내 배너(109 · 1577-0199)만 띄웁니다.
- `none`: "배고파 죽겠다" 같은 관용 표현을 포함한 일반 대화.

프롬프트(`prompts/chat.md`)의 기준과 별개로, 서버(`app/api/chat/route.ts`)가 분명한 위기 표현을 키워드로 한 번 더 확인해 AI가 놓친 경우를 보완합니다.

## 데이터는 어디에 저장되나요

- 대화와 마음정리는 **Supabase(Postgres)** 의 `conversations`, `messages`, `reports` 테이블에 저장됩니다.
- 로그인 대신 **Supabase 익명 로그인**을 사용합니다. 익명 계정 정보는 사용하는 브라우저에 보관됩니다.
- RLS(행 수준 보안) 규칙으로 **본인 데이터만** 읽고 쓸 수 있습니다.
- 브라우저 저장 데이터를 지우거나 다른 브라우저로 접속하면 이전 기록에 접근할 수 없습니다.
- `/counselor` 데모도 같은 규칙을 따라 같은 브라우저의 기록만 보여줍니다. 별도의 공개 읽기 권한은 없습니다.

## 기술 스택

- Next.js (App Router, TypeScript) + Tailwind CSS, 모바일 우선(최대 너비 430px)
- Supabase: 익명 로그인, Postgres, RLS
- OpenAI API: Next.js API Route에서만 호출, JSON 모드(`response_format`)로 응답 수신
- PDF: 인쇄용 레이아웃 + 브라우저 인쇄
- 배포: Vercel (GitHub `main`에 올리면 자동 배포)

## 실행 방법

1. 의존성 설치

   ```bash
   npm install
   ```

2. Supabase 준비
   - 새 프로젝트를 만들고 **Authentication → Sign In / Providers**에서 **Allow anonymous sign-ins**를 켭니다.
   - **SQL Editor**에 `supabase/schema.sql` 내용을 붙여 넣고 실행합니다.

3. 환경변수: 프로젝트 루트에 `.env.local` 파일을 만들고 아래 세 값을 채웁니다. (이 파일은 git에 올라가지 않습니다.)

   ```
   NEXT_PUBLIC_SUPABASE_URL=
   NEXT_PUBLIC_SUPABASE_ANON_KEY=
   OPENAI_API_KEY=
   ```

   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`는 Supabase의 anon 또는 publishable 키입니다. 브라우저에 공개되는 값이며 데이터는 RLS가 보호합니다.
   - `OPENAI_API_KEY`는 서버에서만 읽으며 브라우저로 내려가지 않습니다.

4. 개발 서버 실행

   ```bash
   npm run dev
   ```

   http://localhost:3000 에서 확인합니다.

사용할 OpenAI 모델은 `lib/config.ts`에서 바꿀 수 있습니다.

## 1분 시연 순서

1. 홈에서 **고민 이야기하기**를 누릅니다.
2. 고민을 3~4번 주고받습니다. (예: "발표했는데 팀장님이 아무 말도 안 해서 불안해")
3. 말문이 막히면 **조금 더 대화하기**를 눌러 AI의 다음 질문을 받습니다.
4. **대화 요약하기** → 오늘의 마음정리의 세 탭을 둘러봅니다.
5. **PDF로 내보내기**에서 "대화 원문도 포함하기" 옵션을 보여 줍니다.
6. **저장하고 끝내기** → 홈의 지난 마음정리 목록에서 다시 엽니다.
7. 홈 맨 아래 **상담사 보기(데모)**로 상담사 관점 요약을 봅니다.
8. 상단 **SOS** 버튼으로 위기 연결 화면을 보여 줍니다.

## 폴더 구조

```
app/                 화면(홈, chat, result, sos, counselor)과 API(api/chat, api/analyze)
components/          공통 컴포넌트(리포트 보기, 인쇄 레이아웃 등)
lib/                 Supabase 클라이언트, OpenAI 호출, 설정, 타입
prompts/             AI 프롬프트(chat.md, analysis.md)
supabase/schema.sql  테이블과 RLS 규칙
public/assets/       이미지(hero.png)
CLAUDE.md            요구사항과 진행 순서
```

## AI 이미지 사용

홈 화면 맨 위 배너(`public/assets/hero.png`)는 AI 이미지 생성 도구로 만들었습니다. 앱 색상(세이지 그린 `#9DB89F`, 버터 옐로 `#F5DFA0`)에 맞춰 "창가의 화분과 아침 햇살"을 글자·사람 없는 차분한 플랫 일러스트로 요청했고, 처음 여는 사용자가 안심하고 대화를 시작하도록 따뜻한 분위기를 담았습니다.

## 한계

- 익명 로그인이라 브라우저를 바꾸면 기록이 이어지지 않습니다.
- 사용 횟수 제한이 없어 공개 주소에서 AI 사용량이 늘 수 있습니다.
- 상담사 보기는 데모이며 실제 상담사와 기록을 공유하는 기능이 아닙니다.
- AI의 응답은 틀릴 수 있으며, 진단이나 치료를 대신하지 않습니다.
